# ViniBank — Banking Dashboard

A simulated banking dashboard built with **React and Vite**, focused on modern interface design, reusable components, and interactive financial features.

This is a personal portfolio project developed to practice and demonstrate Front-End development skills.

## Features

- Interactive banking dashboard
- Sidebar navigation
- Financial analytics interface
- Virtual card component
- Transaction history and interactions
- Responsive layout improvements
- Custom React Hook for local storage

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

```bash
git clone https://github.com/Viniboyfull/vinibank.git
```

2. Navigate to the project directory:

```bash
cd vinibank
```

3. Install dependencies:

```bash
npm install
```

4. Install the icons:
```bash
npm install lucide-
```

5. Start the development server:

```bash
npm run dev
```

6. Open the local URL provided by Vite in your browser.
